# Entity-Creator-Helper
A convenient GUI tool for creating custom entities, weapons, and vehicles for Garry's Mod addons. The application generates the necessary Lua files with the correct structure and code templates.

Mod Entity Creator Helper

Удобный GUI инструмент для создания кастомных сущностей, оружия и транспорта для аддонов Garry's Mod. Приложение генерирует необходимые Lua файлы с правильной структурой и шаблонами кода.

## Возможности

- **Создание сущностей**: Генерация сущностей на основе разных базовых классов (base_anim, base_vehicle, base_weapon)
- **Кастомные пресеты/функции**: У вас есть возможность и сохранять свои функции и пресеры баз (В Custom)
- **Предпросмотр кода**: Просмотр сгенерированного Lua кода перед созданием файлов
- **Многоязычный интерфейс**: Английский и русский интерфейс
- **Настраиваемые опции**: Установка спавна, доступа только админам, категорий, авторов и др.
- **Генерация файлов**: Автоматическое создание структуры папок и Lua файлов (shared.lua, init.lua, cl_init.lua)


## Использование

1. Запустите приложение
2. Выберите путь к папке аддона
3. Заполните свойства сущности:
   - Имя сущности (PrintName)
   - ID сущности (технический идентификатор)
   - Базовый класс
   - Путь к модели
   - Категория и автор
   - Дополнительные опции (спавн, только админ)
4. Нажмите "Предпросмотр кода" чтобы увидеть сгенерированный Lua код
5. Нажмите "Создать файлы" для генерации файлов в папке аддона
