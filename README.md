## English Description
A convenient GUI tool for creating custom entities, weapons, and vehicles for Garry's Mod addons. The application generates the necessary Lua files with the correct structure and code templates.

### Features
- **Entity Creation**: Generate entities based on different base classes (`base_anim`, `base_vehicle`, `base_weapon`).
- **Custom Presets**: Save your own functions and base presets in the "Custom" section.
- **Code Preview**: View generated Lua code before creating files.
- **Multilingual Interface**: English and Russian support.
- **Customizable Options**: Set spawnability, admin-only access, categories, authors, etc.
- **File Generation**: Automatically creates folder structures and Lua files (`shared.lua`, `init.lua`, `cl_init.lua`).

### Usage
1. Launch the application.
2. Select the path to your addon folder.
3. Fill in the entity properties:
   - PrintName, Technical ID, Base Class, Model Path, Category, and Author.
4. Click "Code Preview" to see the generated Lua.
5. Click "Create Files" to generate everything in your addon folder.

<a name="russian"></a>
## Описание (Russian)
Удобный GUI инструмент для создания кастомных сущностей, оружия и транспорта для аддонов Garry's Mod. Приложение генерирует необходимые Lua файлы с правильной структурой и шаблонами кода.

### Возможности
- **Создание сущностей**: Генерация сущностей на основе разных базовых классов (`base_anim`, `base_vehicle`, `base_weapon`).
- **Кастомные пресеты/функции**: Возможность сохранять свои функции и пресеты баз (в разделе Custom).
- **Предпросмотр кода**: Просмотр сгенерированного Lua кода перед созданием файлов.
- **Многоязычный интерфейс**: Поддержка английского и русского языков.
- **Настраиваемые опции**: Установка спавна, доступа только админам, категорий, авторов и др.
- **Генерация файлов**: Автоматическое создание структуры папок и Lua файлов (`shared.lua`, `init.lua`, `cl_init.lua`).

### Использование
1. Запустите приложение.
2. Выберите путь к папке аддона.
3. Заполните свойства сущности:
   - Имя (PrintName), ID (идентификатор), Базовый класс, Путь к модели, Категория и автор.
4. Нажмите «Предпросмотр кода», чтобы увидеть результат.
5. Нажмите «Создать файлы» для генерации в папке аддона.
